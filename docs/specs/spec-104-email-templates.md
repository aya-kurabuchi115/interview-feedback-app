## 1. 概要

### 1.1 背景

現在、Supabase のデフォルトメールテンプレートがそのまま使われており、以下の問題がある:
- サービス名「InterviewCoach」が表示されない
- デザインが素朴すぎて信頼感がない
- 日本語化されていない
- ブランドカラーやロゴがない

ユーザーが最初に受け取るサインアップ確認メールが英語のデフォルトテンプレートでは、信頼性の低下やメール確認率の低下につながる。

### 1.2 ゴール

- 全認証メールをサービスブランドに合った日本語テンプレートに置き換える
- HTML メールテンプレートをリポジトリ内で管理し、変更履歴を追跡可能にする
- レスポンシブ対応のメールデザインを適用する

### 1.3 スコープ外

- メール配信基盤の変更（Supabase の SMTP をそのまま使用）
- メール到達率の改善（SPF/DKIM 設定等は別途対応）
- メールの多言語対応（日本語のみ）

## 2. ユーザーストーリー

As a ユーザー, I want サービスのブランドに合ったメールを受け取る so that 信頼感を持ってサービスを利用できる.

## 3. 機能要件

### 3.1 基本フロー

1. ユーザーがサインアップ・パスワードリセット等の操作を行う
2. Supabase がカスタマイズ済みの HTML メールテンプレートを使用してメールを送信する
3. ユーザーがブランドデザインの日本語メールを受信する
4. メール内のボタン（CTA）をクリックして認証フローを完了する

### 3.2 対象メールテンプレート

#### 3.2.1 サインアップ確認メール（Confirm signup）
- 件名: 「InterviewCoach - メールアドレスの確認」
- 本文: サービス名、ウェルカムメッセージ、確認ボタン（ブランドカラー）、有効期限案内、補足テキスト
- CTA: 「メールアドレスを確認する」ボタン → `{{ .ConfirmationURL }}`

#### 3.2.2 パスワードリセットメール（Reset password）
- 件名: 「InterviewCoach - パスワードのリセット」
- 本文: リセット理由の説明、リセットボタン、有効期限の案内、心当たりがない場合の注意
- CTA: 「パスワードをリセットする」ボタン → `{{ .ConfirmationURL }}`

#### 3.2.3 マジックリンクメール（Magic link）
- 件名: 「InterviewCoach - ログインリンク」
- 本文: ログインリンクの案内、有効期限、セキュリティ注意
- CTA: 「ログインする」ボタン → `{{ .ConfirmationURL }}`

#### 3.2.4 メールアドレス変更確認（Change email）
- 件名: 「InterviewCoach - メールアドレスの変更確認」
- 本文: 変更確認の説明、確認ボタン、心当たりがない場合の注意
- CTA: 「メールアドレスの変更を確認する」ボタン → `{{ .ConfirmationURL }}`

### 3.3 代替フロー

- メールクライアントが HTML 非対応の場合: プレーンテキスト版のフォールバック（リンク URL をそのまま表示）

### 3.4 エラーフロー

- テンプレート変数が正しく展開されない場合: Supabase 側のデフォルト動作に依存（テンプレート構文エラーはダッシュボードで即時確認可能）

## 4. 受け入れ基準

- [ ] 全メールにサービス名「InterviewCoach」が含まれる
- [ ] 全メールが日本語で記述されている
- [ ] ブランドカラー（ダークブルー `#1e3a5f` 系）のボタン・ヘッダーが適用されている
- [ ] レスポンシブ HTML メール（モバイル対応、幅 600px 以下で適切に表示）
- [ ] フッターにサービス URL と「このメールに心当たりがない場合は無視してください」が含まれる
- [ ] テンプレート HTML がリポジトリの `docs/email-templates/` に保存されている
- [ ] Supabase Dashboard の Authentication → Email Templates に設定済み

## 5. 技術設計

### 5.1 変更対象ファイル

| `docs/email-templates/reset-password.html` | **新規作成**: パスワードリセットメールテンプレート |
| `docs/email-templates/magic-link.html` | **新規作成**: マジックリンクメールテンプレート |

### 5.2 データモデル（変更がある場合）

変更なし。

### 5.3 API（変更がある場合）

変更なし。

### 5.4 UI コンポーネント（変更がある場合）

変更なし。メールテンプレートは Supabase ダッシュボードで設定する。

### 5.5 テンプレート設計方針

- HTML メールは **テーブルベースレイアウト**（Outlook 互換性のため）
- インラインスタイル使用（メールクライアントの CSS サポートのため）
- 最大幅 600px、モバイル対応
- テンプレート変数: `{{ .ConfirmationURL }}`, `{{ .Token }}`, `{{ .SiteURL }}`

### 5.6 デザインスペック

```
ヘッダー: 背景色 #1e3a5f、テキスト白、サービス名「InterviewCoach」
本文: 背景色 #ffffff、テキスト #333333、パディング 32px
CTA ボタン: 背景色 #1e3a5f、テキスト白、角丸 6px、パディング 14px 28px
フッター: 背景色 #f5f5f5、テキスト #888888、フォントサイズ 12px
```

### 5.7 適用手順

1. `docs/email-templates/` 配下の HTML ファイルを作成
2. Supabase Dashboard → Authentication → Email Templates で各テンプレートの HTML を貼り付け
3. 件名を日本語に変更
4. テストメールを送信して表示確認

## 6. 依存関係

- 前提: Supabase ダッシュボードへのアクセス権限（ユーザー操作が必要）
- ブロック: なし

## 8. リスクと緩和策

| リスク | 影響度 | 緩和策 |
|--------|--------|--------|
| メールクライアントごとの表示差異 | 中 | テーブルベースレイアウト + インラインスタイルで互換性を確保 |
| Supabase テンプレート変数の仕様変更 | 低 | 公式ドキュメントに準拠し、変数名をハードコードしない |
| ダッシュボード設定がコードレビューの対象外 | 中 | テンプレート HTML をリポジトリ管理し、README に適用手順を記載 |
| メールのスパム判定 | 低 | 過度な画像使用を避け、テキスト中心のデザインにする |
